# Code of Conduct

Adapted in spirit from the Contributor Covenant, kept short enough that people actually read it.

## Our standard

- Be respectful and constructive. Critique code and ideas, not people.
- Assume good faith; ask before attributing malice to a mistake.
- No harassment, insults, trolling, or publication of anyone's private information.
- Keep discussions on topic; move long tangents to a dedicated issue.
- Respect that this is a single-maintainer project: reviews and responses may take time.

## Scope

This applies to this repository (issues, pull requests, code review, discussions) and to any other project space, online or offline, where you represent the project.

## Enforcement

Report violations to the maintainer via GitHub (@Chr0nixz). For sensitive matters — including anything that looks like a security issue — use the private channels described in [SECURITY.md](SECURITY.md). The maintainer may edit, lock, or remove content, and may block accounts for repeated or severe violations. Attempts to revive a closed topic after a moderation decision are themselves violations.
